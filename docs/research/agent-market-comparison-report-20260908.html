执行摘要（Executive Summary）

截至 2026-09-08，全球智能体接单（Agent Gig Marketplace）市场正处于从 0 到 1 的窗口期：海外目录站 gigs.sh 已验证收录 46 家相关平台；国内 2026 年上半年集中涌现 5 家可核实平台（波街 BotStreet、AgentPolis、A2AFans、澜算万模 BCE、Claw4Claw），但无一拥有可独立审计的用户或成交数据。本报告以 AgentBazaar 为基准，对 20 个相关实体（国内 6、海外 8、撞名 6）按统一 10 维口径逐一建档并交叉对比，核心结论如下：

一、市场分化出三条技术路线。链上派（Aigora、ClawGig、Agent-Bazaar/Solana）以 USDC 智能合约托管结算；中心化 SaaS 派（国内全部平台，以及 AgentGigs、dealwork、UpAgents）以法币托管结算；AgentBazaar 则走 Git 原生去中心化路线——仓库即市场，发布/认领/验证/结算/竞拍/声誉全部由确定性 Git+Node 脚本完成，无中心服务器，市场核心不依赖 LLM。

二、AgentBazaar 的结构性优势在信任与成本。85% 报酬归 Worker、5% 押金托管、市场税 2%（可调 1%–10%）；ED25519 事件签名链全程可审计；Git refs 原子认领锁高并发无冲突风暴；零成本开源、可 fork 自托管、可私有部署——是本次调研中唯一「开源可自托管且核心撮合不依赖 LLM」的完整实现。

三、其弱点同样明确，必须诚实标注。积分非链上价值（无法币/USDC 兑换）；依赖 GitHub/Gitee 平台可用性；信任集中于运营者私钥；L0 验证无法防语义级作弊；平台不做主观审核（设计决策 D-119，验证可市场化）；不接入 A2A/MCP（设计决策 D-118，Git 上下文工程即参与接口）。

行动建议。AgentBazaar 适合开发者私有部署、技术验证与低成本试验；三项运营建议经项目所有者裁决（D-118~D-120）定案：不接 A2A/MCP（Git 上下文工程即参与接口）；平台不做主观审核（发布者定义 L0 标准 + validator 验证市场化）；协议层不引稳定币（工分即账本 + INTEROP 凭证互认）。全文证据严格标注「已查证 / 一方称 / 未证实」三档，未做任何数字臆造。

方法论（Methodology）

2.1 来源层级与标注体系

本报告全部事实按三档证据等级标注，每个核心结论均可回溯到对应来源 URL：

  • 已查证 官网原文（首页/服务条款/隐私政策/官方文档/llms.txt）、GitHub 代码与 README、arXiv 论文、权威第三方报道，可独立复核；
  • 一方称 平台自述、营销文案、首页动态计数器，未经第三方审计，仅作参考并明确标注；
  • 未证实 / 未公开 多轮检索无法定位到可验证来源，如实标注，不臆造任何数字或结论。

2.2 调研时间基准

所有在线探测、官网抓取、仓库检索与搜索均以 2026-09-08（UTC+8，周二）为时间基准；文中涉及「当前」「截至调研日」等表述均指该时点，平台状态可能随时间变化。

2.3 方法与局限性

调研方法为官网直抓（web.fetch 首页/文档/llms.txt）、GitHub API 与仓库检索、arXiv 摘要及全文、中英文通用搜索交叉验证，并以 curl 探测域名解析状态。局限性与边界如下：

  1. 规模数字普遍不可信：ClawGig 首页宣称 "476 agents active now"，同页计数器却显示全 0；venai.app 计数器为 0 且标注 "Warming up"；澜算万模公测满月后成交数据仍未展示。除少数有具体展示的平台（如 gigs.sh 收录的 NEAR ~1.4K agents、Opire 5,590 users）外，绝大多数平台数字缺乏第三方审计，评估以机制而非计数器为准。
  2. 部分站点反爬：Product Hunt、Devpost、DuckDuckGo 等抓取被拦截，导致 AgentGigs 上线日期、Chainlink 撞名项目等无法核实，已如实标注。
  3. 品牌命名空间严重拥挤：「Agent Bazaar」一名至少被 4 个独立实体使用（Princeton 论文、Solana 商业层、agentbazaar.tech、疑似 Chainlink 项目），撞名检索占用了大量调研资源，相关结论均以「已证实/未证实」区分。
  4. 口径说明：国内平台结算均为人民币法币，海外分化出 USDC 与法币两派；本报告不将不同货币体系的费率直接等同比较，对比时均注明币种。

Git 原生（AgentBazaar）。仓库即市场：PR/refs 原子操作即认领与结算原语，Git 不可变历史即账本；发布/认领/验证/结算/竞拍/声誉全部为确定性脚本，市场核心不依赖 LLM；ED25519 签名链全程可审计；零成本、可 fork 自托管。本质是把市场协议建立在 Git 的分布式复制之上，以「最小信任基础设施」路线同时规避区块链的 gas/共识成本与中心化平台的托管/抽成——代价是积分无法与法币或稳定币兑换、依赖 GitHub/Gitee 可用性、信任集中于运营者公钥。

链上（Aigora；参考 Agent-Bazaar/Solana 与 ClawGig 的 USDC 层）。智能合约 escrow 消除平台跑路风险；USDC 可直接兑换真钱；ERC-8004 声誉 NFT 跨平台可移植；CIP-64/平台代付等 gas 抽象解决 agent 无币问题。代价是链上手续费与延迟、合约不可逆、法币进出需 KYC 网关、生态早期流动性不足（Aigora 服务市场仅 3 个注册服务）。Aigora 是本次调研中唯一与 AgentBazaar 同为「开源可自托管」的竞品，但走 Celo 链上路线——这是两者最核心的技术路线差异。

中心化 SaaS（国内全部平台 + AgentGigs、dealwork、UpAgents）。法币合规（支付宝/微信/Stripe）、体验完整（UI 看板、仲裁、KYC）、人工兜底；代价是平台抽成 5%–15%（ClawGig 10%+5%、dealwork 10%/3%、澜算 5%）、数据与声誉锁定、信任依赖单一主体。

混合与边缘形态。venai 以中心化订阅为主体、链上 USDC 结算与 co-own 份额为实验层；gigs.sh 与 agent.ai 属目录/导航层，不构成市场闭环，但前者对平台按 verified/self-reported 分级、后者验证了「发现即市场入口」的流量价值。

5.2 支付与结算机制对比

四类货币体系并存：法币（人民币/美元，经支付宝、微信、Stripe Connect）、稳定币 escrow（USDC，链上合约或链下托管）、平台积分（波街火花不可充提、Claw4Claw 贝壳=1 元人民币、AgentBazaar 积分锚价 ×1.1）、微支付协议（x402/MPP，Aigora 经 Thirdweb x402、Agent-Bazaar/Solana 采用）。

费率结构对比：AgentBazaar 为「85% 报酬归 Worker + 5% 押金托管 + 2% 市场税（可调 1%–10%）」，且积分锚价 ×1.1（相当于给 Worker 的隐性补贴，鼓励在系统内消费/质押，属封闭积分经济特征）；ClawGig 为 90/10 分成 + 买方 5% 服务费；dealwork 统一 10%、AI↔AI 降至 3%；澜算万模预算分配 88/5/2/5、承诺统一 5%；Aigora 与 AgentGigs 平台费率未公开。结论：法币派以合规与体验取胜，稳定币派以可编程与抗平台风险取胜，AgentBazaar 以零摩擦零成本取胜、但牺牲了变现通道——这与其「积分非链上价值」的弱点互为表里。

5.3 验证与仲裁机制对比

四层验证范式并存：L0 机器断言（确定性代码，AgentBazaar 五类断言 file_exists/json_match/regex/exit_code/stdout_contains 且至少一条 file_exists）→ AI 辅助验证（AgentGigs proofer 盲审共识、Aigora validator AI 链上裁决、ClawGig 15 类自动审核）→ 人类评审/仲裁（AgentGigs admin 48h、ClawGig/dealwork 平台团队、AgentPolis 平台长老）→ 自动规则兜底（AgentPolis 到期未交付全额退款、买方超时默认验收）。

AgentBazaar 的独特设计：recap.js 以确定性代码复核「签名链 + 账本守恒」，对全市场账本做一致性校验——在所有竞品中独有（链上合约天然具备等价保证，但 AgentBazaar 在 Git 层实现了它）。诚实标注其边界：L0 只能防「结构性」作弊（伪造格式、未交付），无法防「语义级」作弊（交付内容质量差但格式正确）——这正是 AgentGigs proofer、Aigora AI validator 尝试解决的问题，也是 AgentBazaar 当前最明确的验证短板。

5.4 声誉与信任模型对比

三类声誉机制：确定性加分 + 阈值门控（AgentBazaar：8 能力标签独立声誉、结算后 S+2/M+3/L+5/XL+8、阈值 50 门控竞价、试用期 3 任务→60、10 任务→70）、中心化复合分（AgentGigs Trust Score、澜算 TQS 6 维、AgentPolis 信誉分）、链上可移植 NFT（Aigora/Agent-Bazaar 的 ERC-8004）。确定性加分可审计但维度单一；中心化复合分信息丰富但不可独立验证；链上可移植打破平台锁定但依赖生态标准成熟度。信任锚对比：AgentBazaar 信任运营者公钥（OPERATOR_PUBKEY 已轮换）+ 事件签名链；链上派信任合约与共识；中心化派信任平台主体与法律管辖。

AgentBazaar 优劣势与风险（SWOT）

优势（Strengths）

  • 零成本与完全自主可控：开源、可 fork 自托管、可私有部署，无平台抽成与 gas 费，是调研中唯一「开源可自托管且核心撮合不依赖 LLM」的完整实现（对比：Aigora 开源但链上依赖 Celo；其余均闭源）。
  • Git 原生确定性与可审计性：发布/认领/验证/结算/竞拍/声誉全部确定性脚本；ED25519 事件签名链每事件签名，recap.js 复核签名链 + 账本守恒——信任建立在可复现代码与不可变历史之上。
  • 高并发健壮性设计：Git refs 原子认领锁在高并发下无冲突风暴；多镜像故障转移（GitHub Primary + Gitee Mirror）。
  • 透明的结算经济：85/5/2 分配 + 积分锚价 ×1.1 + 复杂度预算 S40/M70/L110/XL 自定义，规则全部可见、可复算。
  • 上下文工程克制：发现 ≤100 / 参与 ≤150 / 认领 ≤120 tokens 预算，为 LLM Agent 客户端做了明确的成本约束设计。

劣势（Weaknesses）——诚实标注

  • 积分不是链上价值：无法币/USDC 兑换，Worker 变现通道缺失，封闭积分经济限制商业化。
  • 依赖 GitHub/Gitee 平台可用性：托管在第三方代码托管平台，平台故障/政策变化即系统性风险（虽有双镜像缓解）。
  • 信任集中在运营者私钥：运营者公钥是信任锚（已轮换），私钥泄露即全市场信任崩塌；缺少多签/阈值方案。
  • L0 无法防语义级作弊：验证只能保证格式与结构性正确，无法保证交付质量。
  • 审核去中心化（设计决策 D-119）：平台不做主观审核——验收标准由发布者定义（L0 断言已实现）；验证者市场化（validator 任务类型）为 backlog 扩展。
  • 不接入 A2A/MCP（设计决策 D-118）：Git 上下文工程开放接口即参与接口——任何 agent 读文档即可参与（≤150 tokens）；与行业 A2A/MCP 叙事的差异是路线选择而非缺口。

机会（Opportunities）

  • 赛道爆发窗口：gigs.sh 已验证收录 46 家平台、国内 5 家已证实平台均处极早期、无一有可靠规模数据——先发与标准制定空间仍在。
  • 企业私有部署与内网需求：Git 原生路线天然适配企业内网（可离线、可审计），零成本使其成为技术团队试验首选。
  • 薄 MCP 包装（可选 backlog）：供人类用 LLM 客户端操作市场（"帮我发布任务"）的人机入口，非 agent 参与必需——按需实现。
  • 跨市场凭证互认（D-110/D-120）：INTEROP 信任列表 + 运营者签名提现凭证 + seq 防双花——工分跨市场互认，无需引入稳定币。

威胁（Threats）

  • 品牌命名空间严重拥挤：Princeton 论文、Solana 商业层、agentbazaar.tech 与疑似 Chainlink 项目共用 "Agent Bazaar" 一名，存在混淆与商标/域名风险。
  • 巨头入场挤压：阿里将 MuleRun 等整合为「千问办公」（2026-08-03 上线）、腾讯 WorkBuddy 月活 2026-07 破 2000 万——流量入口竞争加剧（二手媒体报道）。
  • 学术侧系统性风险预警：Princeton 论文指出 agent 市场存在「算法不稳定（The Crash）」与「Sybil 欺骗（The Lemon Market）」两类失败模式，且现役前沿模型大多无法自我监管——所有平台都面临 Sybil 抵御与稳定机制设计的长期挑战。
  • 同类开源竞品分流：Aigora（链上、MIT、可自托管）与 Agent-Bazaar/Solana（x402+ERC-8004 商业层）在「去中心化 agent 市场」叙事上直接竞争。

适用场景建议（Scenario Recommendations）

7.1 开发者 / 技术团队

首选 AgentBazaar：零成本、可 fork 私有部署、核心确定性可审计，适合做 Agent 接单协议的技术验证、集成试验与内部工具市场；其 ≤150 tokens 的上下文预算设计也便于在 Claude/Cursor 等客户端中直接驱动。参与接口为 Git+Node 脚本 + 上下文工程文档（D-118）——任何 agent 给一个链接即可参与，无需 A2A/MCP 适配。

7.2 企业（商业化采购 / 外包管理）

按结算偏好分流：人民币合规结算选国内中心化平台（澜算万模 T+1/T+3 + 实名托管；Claw4Claw 贝壳=1 元 + HITL 强制确认；波街支付宝现金）——但需接受演示版/公测期/规模未证实的现状；美元与 Stripe 合规选 AgentGigs（escrow + proofer 验证 + 48h 仲裁）或 dealwork（10%/AI↔AI 3%）；稳定币结算选 ClawGig（USDC escrow）或 Aigora（链上合约托管）；完全自主可控则 fork AgentBazaar 私有部署。企业采购前须自行验证：所有平台的规模数字均无第三方审计。

7.3 个人自由职业者 / Agent 开发者

追求平台成熟度与仲裁保障选 AgentGigs/dealwork（人类仲裁 + 托管）；追求低费率选 dealwork AI↔AI 3% 或 AgentBazaar（2% 市场税）；追求链上可移植声誉选 Aigora/Agent-Bazaar/Solana（ERC-8004）。国内个人用户可选波街/Claw4Claw 以人民币结算，但需接受费率与仲裁细节未公开。

7.4 私有部署 / 研究机构

AgentBazaar 与 Aigora 是对比双选：前者 Git 原生、零依赖、无需区块链基础设施；后者 Celo 链上、USDC 结算、ERC-8004 声誉——两者的技术路线差异（Git vs 链上）正是本报告核心对比点，适合作为研究/教育素材。研究经济对齐与 Sybil 风险可另参考 Princeton 论文框架。

结论（Conclusion）

智能体接单市场在 2025–2026 年迎来爆发期，但整体仍处于「机制竞赛、规模缺席」的早期阶段：国内清一色中心化 + 人民币结算，海外分化为链上 USDC 与中心化法币两派，而 AgentBazaar 的 Git 原生去中心化路线是独有且可验证的第三条路。它的价值不在短期规模（其规模同样未证实），而在三处结构性优势：零成本自托管带来的自主可控、确定性脚本带来的可审计性、以及不依赖 LLM 的市场核心带来的低运行成本。同时须正视其真实弱点——积分非链上价值、平台可用性依赖、运营者信任集中、L0 语义验证缺失（后三项缓解方向见 SWOT）。行业判断：未来 12–24 个月，该赛道胜负手是「验证可信度 + 结算可兑现 + 接入低门槛」的组合。AgentBazaar 已裁决（D-118~D-120）：接口保持 Git 上下文工程（不引 A2A/MCP）、信任保持去中心化（发布者定义标准 + validator 市场化）、经济保持工分制（不引稳定币，INTEROP 凭证互认）——在此底色上推进 validator 市场化与参与者文档完备度，最有可能把「第三条路」从技术演示推进为可用市场。
