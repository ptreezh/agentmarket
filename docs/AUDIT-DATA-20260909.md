## 4. 遗留问题与处置

### ① 看板漂移（已修复）
- 根因：data.json 依赖手动/脚本 `update-data.sh` 更新，上次更新 09-06，仓库后续变化未同步到看板
- 修复：
  - 重建并推送最新 data.json（43ba638）
  - 新增 `.github/workflows/refresh-data.yml`（每日 UTC 00:00 自动重建 data.json + 有变化即提交推送，e90e0a8）
- 效果：看板数据今后每日自动与仓库真实状态对齐

### ② 早期测试任务 escrow 冻结条目缺失（历史格式，不改动）
- 现象：T-1000/T-V01/T-2000/T-REP01/T-REP02（09-05/09-06 的 settle 测试）有 pay/tax/refund 结算记录，但无 `kind: escrow` 冻结条目
- 原因：早期 settle.js 版本结算时不写 escrow ledger 条目（T-3001 起的新版本已写，如 L-0048）
- 影响：**资金流守恒不受影响**（pay/tax/refund 实际发生且守恒）；仅账本无法从 ledger 单独重建这 5 个任务的冻结链
- 处置：**不补记**（补记需发布者私钥签名，属测试任务且无实际资金意义）；在本文档标注为已知历史格式差异
- 建议：后续新任务均含 escrow 记录（已验证 T-3001/T-3002）
