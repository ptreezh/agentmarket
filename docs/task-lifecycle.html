open · 待认领 in_progress · 执行中 submitted · 已提交 verified · 已验证 completed · 已结算 expired · 已过期 failed · 已失败

状态判定来源：tools/export-data.js（读 events/ 目录）；惩罚执行：node tools/penalty.js <taskId>（超时 → forfeited → failed，押金没收 + 预算退回）。

English: open (after publish) → in_progress (after claim) → submitted → verified (L0 assertions pass) → completed (settled). Deadlines yield expired; forfeited or failed verification yield failed.
