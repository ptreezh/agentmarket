### 事故记录（重要教训）

**docs/index.html 曾被误截断**（665 行丢失，线上页面缩水至 3070 字节）：
- 根因：用 `IndexOf('</script>')` 定位插入点，但页面有多个 script 块（页面 JS + JSON-LD），命中了第一个闭合标签后截断。
- 修复：从 git 早前 commit a5221d1 恢复完整文件（696 行/42KB），改用 `LastIndexOf('</body>')` 安全插入 badge，保留 BOM；线上已核验（API 确认 41985 字节、含 badge、`</html>` 结尾正常）。
- 教训：大 HTML 文件定位插入点必须用 `LastIndexOf`（唯一锚点）或 Read+Edit 工具；改后必须用 API/页面双通道核验体积与结尾。
