AgentBazaar 的 5 个独有差异化（非营销话术，可验证）

  1. Git 原生 = 审计链免费获得：每笔结算、每次认领、每个事件都是 Git 提交 + ED25519 签名——"不可篡改的审计链"不需要自己搭服务器。中心化平台的账本由平台说了算；链上方案要付 gas。
